# Plan: Phase 2 - Boot & Login

## Overview

Implement the Boot Sequence and Login Screen UI components in Dioxus and integrate them into the main OS state machine in `packages/web/src/main.rs`.

## Implementation Steps

### 1. Add Timer Dependencies

- Add `gloo-timers = { version = "0.3.0", features = ["futures"] }` to `packages/web/Cargo.toml` or `packages/ui/Cargo.toml` to support the sleep intervals for web.
- Note: If targeting fullstack with `tokio`, we can use `tokio::time::sleep`, but since `tfish` was client-side, web-first makes sense here.

### 2. Implement BootSequence Component

- Create `packages/ui/src/boot_sequence.rs`.
- Define an array of static boot strings.
- Use `use_signal(|| 0)` to track the number of lines visible.
- Spawn a `use_future` (or `use_coroutine`) that iterates and awaits `gloo_timers::future::sleep` for 100ms, incrementing the signal until complete.
- Take an `on_complete` closure/EventHandler prop to notify the parent when boot is done.
- Implement the UI rendering the visible strings with `terminal-glow` and `typing-effect` classes.

### 3. Implement LoginScreen Component

- Create `packages/ui/src/login_screen.rs`.
- Use `use_signal(|| js_sys::Date::new_0())` or `chrono::Local::now()` for time. (If web, `js_sys` is easiest, but `chrono` is more idiomatic Rust. Let's add `chrono` with `wasmbind` feature).
- Implement a timer loop to update the clock every second.
- Implement `is_logging_in` signal. On click, set to true, await 1.5s, then fire `on_login` EventHandler.
- Implement the UI using the classes from `tfish/src/components/LoginScreen.tsx` (using standard CSS classes and inline SVG for the Login icon).

### 4. Update Workspace App Component

- Update `packages/web/src/main.rs`.
- Introduce an `enum OsState { Booting, Login, Desktop }`.
- Track state with `use_signal(|| OsState::Booting)`.
- Use match statement to render:
  - `OsState::Booting` -> `<BootSequence on_complete=... />`
  - `OsState::Login` -> `<LoginScreen on_login=... wallpaper=... />`
  - `OsState::Desktop` -> `div { "Desktop (Coming in Phase 4)" }`

### 5. Wire Up Modules

- Expose the new components from `packages/ui/src/lib.rs`.

## Verification

- Test `dx serve`.
- Ensure Boot Sequence plays out and then transitions.
- Ensure Login screen shows ticking time.
- Ensure Login button works and transitions to the placeholder Desktop state.
