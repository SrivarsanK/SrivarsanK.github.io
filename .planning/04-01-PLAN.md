# Plan: Phase 4 - Desktop Environment

## Overview
Implement the desktop environment consisting of interactive, draggable icons and connect them to the layout in `packages/web/src/main.rs`.

## Implementation Steps

### 1. Implement DesktopIcons Component
- Create `packages/ui/src/desktop_icons.rs`.
- Define a component `DesktopIcons` with an `on_icon_click` `EventHandler<String>` prop.
- Define a sub-component `DesktopIcon` with props:
  - `label: String`
  - `command: String`
  - `on_double_click: EventHandler<String>`
  - `initial_pos: (i32, i32)`
  - `icon: Element` (SVG content representation)

### 2. Implement Drag-and-Drop Hook/Effect in DesktopIcon
- In `DesktopIcon`:
  - Create signals: `pos = use_signal(|| initial_pos)`, `is_dragging = use_signal(|| false)`.
  - A thread-local or static reference to the start click position or offsets isn't needed if we can capture it in mutable state or closure. Let's use `use_signal(|| (0, 0))` to store `drag_offset` (the mouse position minus current element position at start of drag).
  - Add `onmousedown` handler:
    - Set `is_dragging` to `true`.
    - Record `drag_offset = (e.client_x() - pos().0, e.client_y() - pos().1)`.
  - Add a `use_effect` that registers window listeners when `is_dragging` is true:
    - Listen for `mousemove`: update `pos` to `(e.client_x() - drag_offset.0, e.client_y() - drag_offset.1)`.
    - Listen for `mouseup`: set `is_dragging` to `false`.
    - Clean up listeners when the effect runs again or component unmounts.

### 3. SVG Assets / Icons
- Translate standard SVG layouts from Lucide React to Dioxus inline RSX for:
  - User (About Me)
  - Folder (Projects)
  - Ghost (Waifu)
  - Smile (Joke)
  - Trash2 (Recycle Bin / Clear)

### 4. Wire Up Modules
- Export `DesktopIcons` in `packages/ui/src/lib.rs`.
- Render `<DesktopIcons on_icon_click=move |cmd| { ... } />` inside the main layout of `packages/web/src/main.rs` (under `OsState::Desktop` render).
- For now, log the clicked icon command to browser console to verify it triggers correctly before the terminal component is wired in.

## Verification
- Serve with `dx serve`.
- Verify icons load.
- Test dragging each icon to different positions and verify they drop in place correctly.
- Test double-clicking icons and verify console prints expected log messages (e.g. `Double-clicked icon with command: about`).
