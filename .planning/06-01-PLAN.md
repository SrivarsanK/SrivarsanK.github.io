# Plan: Phase 6 - Final Polish

## Overview

Implement final polish features for the Terminal window: Dynamic Theming, Auto-Scrolling, and Input Focus Management.

## Implementation Steps

### 1. Dynamic Theming Integration

- Modify `packages/ui/src/terminal.rs` to accept `theme: Signal<String>` in `TerminalProps`.
- Update `packages/web/src/main.rs` to pass `current_theme` to the `Terminal` component.
- In `terminal.rs`, map the current theme string (e.g., "powershell", "ubuntu", "dracula", "matrix", "retro") to specific CSS classes or inline styles for background and text colors.
  - E.g., `powershell` -> `#012456` background, white text.
  - `ubuntu` -> `#300a24` background, white text.
  - `matrix` -> `#000000` background, `#00ff00` text.
- Apply these dynamically to the Terminal body container and input prompt.

### 2. Auto-Scroll Implementation

- In `packages/ui/src/terminal.rs`, use `web_sys` to scroll the terminal container to the bottom.
- Give the terminal body container an id, e.g., `id: "terminal-body"`.
- Add a `use_effect` hook that depends on the `lines.read().len()` signal.
- Inside the hook, retrieve the DOM element via `web_sys::window().unwrap().document().unwrap().get_element_by_id("terminal-body")`.
- Call `.set_scroll_top()` using `.scroll_height()` on the element.

### 3. Input Focus Management

- Give the input element an id, e.g., `id: "terminal-input"`.
- Add an `onclick` handler to the main terminal body container.
- When clicked, retrieve the `terminal-input` element via `web_sys` and call `.focus()`.
- This ensures users don't have to precisely click the input line to type.

## Verification

- Run `dx serve`.
- Change theme in the Taskbar and verify terminal changes color instantly.
- Spam the `help` command and verify that the scrollbar automatically moves to the bottom to keep the active prompt visible.
- Click randomly inside the terminal window and verify the text cursor focuses on the input line.
