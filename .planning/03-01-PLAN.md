# Plan: Phase 3 - Taskbar

## Overview
Implement the sticky Taskbar component, start menu, system tray controls (wallpaper, theme selection), and clock. Connect it to the app layout in `packages/web/src/main.rs`.

## Implementation Steps

### 1. Add web-sys Dependency
- We will need `web-sys` with `FileReader`, `HtmlInputElement`, `File`, and `FileList` features to read local wallpaper files on the client.
- Add `web-sys = { version = "0.3.70", features = ["FileReader", "HtmlInputElement", "File", "FileList"] }` to `packages/ui/Cargo.toml`.

### 2. Implement the Taskbar Component
- Create `packages/ui/src/taskbar.rs`.
- Define the `Taskbar` component with props:
  - `current_theme: Signal<String>`
  - `wallpaper: Signal<Option<String>>`
  - `on_logout: EventHandler<()>`
  - `on_reset: EventHandler<()>`
- Keep track of:
  - `is_start_open: Signal<bool>`
  - `is_theme_open: Signal<bool>`
  - `is_reset_open: Signal<bool>`
- Render the sticky bottom footer.
- Render the Start Menu. Pinned links will be static in Rust (GitHub, Email).
- Render the Reset Confirmation Modal.
- Render the Theme selector dropdown. Available themes:
  - PowerShell (`#012456`)
  - Classic CMD (`#000000`)
  - Matrix (`#000500`)
  - Ubuntu (`#300a24`)
  - Dracula (`#282a36`)

### 3. File Upload Logic for Wallpaper
- Create a file input: `<input type="file" accept="image/*" class="hidden" />`
- Use Dioxus events to catch `onchange`.
- In the handler:
  ```rust
  let files = e.files();
  if let Some(engine) = files {
      // Since it's web, we can obtain the file and use FileReader via web-sys to read to DataURL.
      // We will write a small helper function `read_wallpaper_file` to handle this.
  }
  ```

### 4. Clock and Date Display
- Use `chrono::Local::now()` and `use_coroutine` to update the clock every second, exactly like in the login screen.

### 5. Wire Up modules
- Export `Taskbar` in `packages/ui/src/lib.rs`.
- Integrate `Taskbar` in `packages/web/src/main.rs` inside the `OsState::Desktop` render.
- Introduce `current_theme` and `wallpaper` state signals at the root `App` component level so they persist and are passed down.

## Verification
- Run `dx serve` and verify the taskbar layout, clocks, start menu toggles, theme changes, reset dialog, and wallpaper changes.
