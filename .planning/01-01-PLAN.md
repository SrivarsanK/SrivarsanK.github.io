# Plan: Phase 1 - Foundation

## Overview

Set up the fundamental Dioxus 0.7 workspace and global CSS structures. This serves as the bedrock for the OS/terminal UI components.

## Implementation Steps

### 1. Configure Workspace & Dependencies

- Verify the workspace structure in `Cargo.toml`.
- Ensure `dioxus` is version `0.7` and has required features (`web`, `router`, etc.).
- Ensure `assets` directory is set up correctly for static files.

### 2. Set up Global CSS

- Create or modify `packages/web/assets/main.css` (or `index.css`).
- Add basic CSS reset.
- Add CSS variables for colors (themes) and fonts (inter, monospace).
- Use `document::Stylesheet` in the root component to inject the CSS.

### 3. Setup Root App Component

- Create the main `App` component routing logic.
- Render a basic placeholder text (e.g. "OS Booting...") to confirm it works.
- Include the `Stylesheet` reference.

## Verification

- Run `dx serve`.
- Ensure there are no compilation errors.
- Ensure the placeholder text renders with the correct font applied from the global CSS.
