# Plan: Phase 5 - Terminal Window

## Overview
Implement the `Terminal` component providing the core CLI functionality of the OS, integrating command execution, HTTP requests for API-based commands, and window management (dragging, resizing, maximizing, minimizing).

## Implementation Steps

### 1. Add Network Dependencies
- Add `reqwest` dependency in `packages/ui/Cargo.toml` with the `json` feature. (Since this is compiled to WebAssembly, `reqwest` will automatically use the browser's Fetch API).
- Add `serde` and `serde_derive` or `serde_json` to parse API responses for the `waifu` and `joke` commands.

### 2. Implement Terminal Core Components
- Create `packages/ui/src/terminal.rs`.
- Define `struct TerminalLine` containing `id`, `line_type` (Input, Output, Error, Info, Component), and `content` (String). Since some commands (waifu, joke) output complex HTML, we can represent them via components or just embed raw HTML if it's simple, or use an Enum for `Content` to specify if it's raw text or a rich component (like `WaifuImage`, `JokeDisplay`).

### 3. Implement Command Parser & Async Handlers
- Map string inputs to static outputs for simple commands (`help`, `about`, `skills`, `projects`, `contact`, `whoami`, `date`).
- Implement async fetching commands:
  - `waifu`: Spawn a future that fetches from `https://api.waifu.pics/sfw/waifu`. Append a loading message line first. Upon completion, append a new line containing the image.
  - `joke`: Spawn a future fetching from `https://v2.jokeapi.dev/joke/Any`. Append loading message, then parsed joke text.
- Connect input keydown events for Enter (submit), Arrow Up/Down (history cycle), and Tab (autocomplete).

### 4. Implement Windowing System
- Inside the Terminal component, track:
  - `pos = use_signal(|| (0, 0))`
  - `size = use_signal(|| (800, 500))`
  - `is_maximized = use_signal(|| false)`
  - `is_minimized = use_signal(|| false)`
- Using the same `onpointerdown`/`onpointermove`/`onpointerup` strategy established in Phase 4 (by putting listeners on the `div` wrapper inside the Desktop, or directly capturing pointer in the header/resizer):
  - Add drag logic to the terminal header.
  - Add resize logic to the bottom right corner.
- Implement Maximize and Minimize buttons in the header.

### 5. Desktop Integration
- In `packages/web/src/main.rs`:
  - Add a shared signal: `let mut external_command = use_signal(|| None::<String>);`
  - Pass this signal to `DesktopIcons` and `Terminal`.
  - When a Desktop Icon is double-clicked, set the signal to the command name.
  - Inside `Terminal`, use a `use_effect` depending on `external_command` to intercept new strings and execute them automatically.

## Verification
- Run `dx serve`.
- Execute static commands (`help`, `about`).
- Execute dynamic commands (`waifu`, `joke`) to ensure async fetch operations are successful.
- Test terminal dragging, maximizing, minimizing, and resizing.
- Test double-clicking a desktop icon to verify it injects and runs the command inside the terminal window.
